# AuditForge — Source Reference

This document catalogs the authoritative sources AuditForge's hardening rules and rationale are derived from. Each entry was gathered via live web research and reflects the state of the source **as observed on the retrieval date below**, not necessarily the state at the time this file is read. Where a research pass could not verify a fact (a date, a version, a license clause, exact wording, etc.), that caveat is preserved verbatim in the Notes column rather than being smoothed over or guessed. No URL or date below was invented — every value traces to the underlying research record.

**Retrieved Date for all entries: 2026-09-24**

**Licensing note (read before quoting any source in code/docs):** CIS Benchmark text is redistribution-restricted (see the CIS section below) — AuditForge must reference CIS content by **control ID only** (e.g., "CIS Benchmark for Ubuntu 22.04 LTS, control 1.1.1.1"), never by reproducing CIS's descriptive/rationale text or rehosting CIS PDFs.
